# Research Log - August 08th, 2026

## Today's Goals

The goal for today's work is to implement a synthetic time series data function with parameters for 
 - the number of samples
 - a seed for reproducibility
 - level of noise
 - optional toggle for injecting a shortcut feature
 - train split ratio (default 0.7)
 - validation & test split ratios (default 0.15 respectively).

For the sake of simplicity, a linear combination of a sine and linear trend function, inspired by Annual Seasonality function from YData, will be the initial choice for synthesizing time series data. The generated data will then include added Gaussian noise to slightly deviate from the true target. 

The data will be split as follows:
 - time
 - linear trend
 - annual seasonality
 - target
 - split

Today's work will be completed once the following benchmarks / thresholds have been met:
 - Synthetic data is able to be generated
 - Determinism by seed
 - Test on time-based split passes, such that the training data always comes before the validation and test splits
 - Shortcut behavior closely correlates with function output in the training data (> 0.8), but close-to-none in the validation & test splits (< 0.2). (Deferred)
 - Scalability of the data, such that scaling is fit with respect to the training data. This same scaling is then applied to the validation & test splits as soon as tests verify that training features remain centered. (Deferred)
 - Visualization of the synthesized data.
